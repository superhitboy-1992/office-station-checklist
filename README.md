# 驻站检查登记系统（本地网页应用）

供公交公司驻站检查使用：现场快速登记每辆车的检查信息，数据保存在本机浏览器中，
后期按「日期 + 站点」一键导出与现成模板《驻站记录表.xlsx》格式一致的 Excel 表格。

## 使用方法

### 电脑使用

用 **Chrome 或 Edge** 浏览器双击打开 `index.html`，无需安装任何软件，无需联网。

### 手机使用（推荐 PWA 安装）

手机是主要使用场景，建议部署后把本系统「添加到主屏幕」，像 App 一样全屏、离线使用：

1. 在手机浏览器打开部署好的网址（见下方「部署到静态托管」）；
2. 安卓 Chrome：右上角菜单 →「添加到主屏幕」；
   苹果 Safari：底部分享按钮 →「添加到主屏幕」；
3. 若在微信中打开，请先点右上角「···」→「在浏览器中打开」。

安装后在主屏幕点图标即可进入，断网也能正常登记和查询。

### 日常操作

1. 「登记记录」页填写并保存：站点、驻站人、日期、时间、线路、车号、上客人数、
   进出站规范（√/×）、售票员招呼（√/×）、检查情况、整改措施、备注。
   站点、驻站人、日期为「本次检查信息」，登记多辆车时保持不变，换站时可点
   「开始新检查」一键清空；时间、线路、车号、上客人数等「车辆登记信息」保存后
   自动清空，可连续登记下一辆。线路、车号会自动记忆（用于快捷选择）。点字段或
   输入时自动模糊匹配：支持汉字（如输入「莲朱」）和拼音首字母/全拼（如输入「lz」
   或「lianzhu」），手机上点字段弹出选择层，电脑上输入时直接出现候选。
2. 「资料库」页维护完整名单：站点、驻站人、线路三类数据，可从现成 Excel 一键导入
   （支持 .xlsx/.xls/.csv，自动按表头识别列，重复项自动跳过），也可随时手动添加、
   删除、清空；所有修改立即生效，登记时的匹配和选择都会用到。
   首次打开时系统已内置这三份名单，无需手动导入；后续 Excel 有更新时再重新导入即可。
3. 「记录查询」页按日期、站点、线路、关键字筛选，可编辑或删除记录；手机端显示为卡片列表。
4. 「导出表格」页选择日期范围，系统按「日期 + 站点」分组；
   每组以内置模板《驻站记录表【日期】.xlsx》为底稿，只把登记数据填入表格，
   格式与模板完全一致；文件名形如《驻站记录表【8.17】.xlsx》（日期替换占位符）。
   也可批量导出成一个 ZIP；同日期多站点批量导出时文件名自动追加站点名避免覆盖。
   手机上单组导出可直接分享到微信/邮件。
5. 「设置」页维护常用车号，并支持整体数据备份；请定期「导出数据（JSON）」备份。
   登记达到 50 条或距上次备份超过 7 天时，登记页会提醒备份。

## 部署到静态托管

PWA 的离线能力要求 HTTPS 才能生效，推荐用免费静态托管（二选一）：

### GitHub Pages

1. 在 GitHub 新建仓库（如 `zzjc-checkin`），把本目录所有文件上传到仓库；
2. 仓库 `Settings → Pages`，Source 选择 `Deploy from a branch`，分支选 `main`，目录 `/ (root)`，保存；
3. 稍等片刻，访问 `https://<用户名>.github.io/zzjc-checkin/` 即可，手机浏览器打开后添加到主屏幕。

### Cloudflare Pages

1. 登录 Cloudflare → Pages → Create a project → 连接 Git 仓库（或直接拖拽本目录上传）；
2. Build settings 保持默认（纯静态，无需构建命令）；
3. 部署完成后会得到一个 `https://<项目名>.pages.dev` 地址，自带 HTTPS。

## 更新版本

网页更新 = 重新上传文件：把新版文件覆盖上传到仓库/托管平台，重新部署即可。
Service Worker 会检测到文件变化并自动更新缓存，下次打开就是新版；
如个别手机上仍显示旧版，关闭标签页重新打开一次即可。

## 生成表格格式

生成文件以内置模板《驻站记录表【日期】.xlsx》为底稿（由
`tools/build-template.js` 打包进 `js/template-data.js`），只填写登记数据，其余
格式原样保留；如模板有改动，重新运行 `node tools/build-template.js` 即可：

- 工作表「表格」，A1:J34；
- 标题"驻站记录表"，第二行自动填写"驻站站名:XX站""驻站人:姓名""8月16日"；
- 表头：序号、线路、车号、过站时间、上客人数、进出站规范、售票员招呼、检查情况、整改措施、备注；
- 30 行记录区（一天最多登记 30 条），宋体、细边框、行高列宽一致；
- A4 纵向、56% 缩放、打印区域 A1:J34。

## 文件结构

```
index.html          应用入口（双击打开）
manifest.json       PWA 清单（名称、图标、全屏显示）
sw.js               Service Worker（离线缓存与自动更新）
css/style.css       界面样式
js/core.js          数据分组、格式化等纯逻辑
js/catalog-data.js  内置初始资料库（由 database 表格生成）
js/search.js        模糊搜索（汉字子串 + 拼音匹配）
js/xlsx-import.js   Excel 导入解析（懒加载 SheetJS）
js/template-data.js 内置导出模板（由 build-template.js 生成，勿手改）
js/xlsx-writer.js   零依赖 Excel 导出器（以内置模板为底稿填充数据）
js/app.js           页面交互逻辑
js/vendor/          离线依赖（SheetJS、pinyin-pro）
tools/build-catalog.js  重新生成内置资料库（node tools/build-catalog.js；原始 Excel 仅保留在本机 database/ 目录，不入库）
tools/build-template.js 重新打包内置导出模板（node tools/build-template.js）
icons/              PWA 图标（192/512 与苹果图标）
README.md           本说明
```

## 数据说明

- 数据保存在当前浏览器（本机）的 localStorage 中，不上传任何服务器；
- 清理浏览器数据、换手机/电脑会导致数据丢失，务必先在「设置 → 数据备份」导出 JSON；
- 同一台设备上不同浏览器（Chrome / Edge / 微信）的数据互不相通；
- 登记达到 50 条或距上次备份超过 7 天时，登记页会提醒备份。
